Discreet Pure Grex JS v1.0.0 Multi-VPS Control Panel, Encrypted 127.0.0.1 SSH Database Tunnels & Site DNA Fleet Deployer

Why Gashboard Is Different (Plain-English Summary):
Traditional hosting panels leave an admin login page open on the public internet (like port 8080 or 8443) for bots to attack. Gashboard does the opposite: the dashboard lives safely on your own computer (127.0.0.1 only) and connects to your servers exclusively over encrypted SSH keys pinned in your known_hosts file. No public control-panel ports, no exposed database ports, and 1-click rollbacks before every deployment.

1. What Is Included in Gashboard v0.1.0

  • Stealth 127.0.0.1 Control Panel (GRAB v1.1.0 + Pure Grex JS v1.0.0): Refuses public 0.0.0.0 bindings by default. Contains zero wrapper <div> tags, zero innerHTML writes, 100% WCAG AA accessible contrast, and exact base-10 decimals (ADR-025c).
  • AES-256-GCM Local Credential Vault: Any SSH passphrases or agent references you register are encrypted immediately using GRAB use crypto AES-256-GCM before touching local SQLite storage, and never sent back in API responses.
  • Pure Go Loopback SSH & Tunnel Sidecar (gashboard-bridge): Enforces OpenSSH known_hosts host-key fingerprint pinning (zero InsecureIgnoreHostKey), opens up to 8 concurrent 127.0.0.1:<port> private tunnels to PostgreSQL, MariaDB, or Redis, and proxies remote grabtaculousd nodes safely.
  • 1-Click Hardened App Marketplace: Deploys GrabLab CMS + Grex Theme Builder + Groxy AI or private databases in read-only hardened containers with automatic Caddy, Nginx, or Cloudflare Tunnel SSL—after generating a safety plan and single-use approval confirmation.
  • Portable Site DNA Fleet Deployer & Instant Rollbacks: Validates Groxy AI Site DNA bundles against grabman.lock, triggers zero-downtime grabtaculous rollouts, and lets you revert any server in one click via automatic Pre-Deploy Snapshots.

2. Quickstart: Starting Gashboard Locally

  1. Start the Local Go SSH Bridge (Terminal 1): 
    set GASHBOARD_BRIDGE_TOKEN=replace-with-random-secret
gashboard-ssh-windows-amd64.exe --listen 127.0.0.1:9391 --known-hosts %USERPROFILE%\.ssh\known_hosts
  2. Initialize Local SQLite Vault & Start Gashboard (Terminal 2): 
    grab migrate --db-config grab.data.json --allow-db main:migrate migrations\001_gashboard_schema.grab
set GASHBOARD_MASTER_KEY=replace-with-strong-passphrase
set GASHBOARD_BRIDGE_URL=http://127.0.0.1:9391
grab serve --addr 127.0.0.1:9390 --allow-scripts --static public ^
  --db-config grab.data.json --allow-db main:read-write ^
  --platform-config grab.platform.json --allow-cache gashboard:read-write ^
  --allow-read . --allow-write storage ^
  --allow-env GASHBOARD_MASTER_KEY,GASHBOARD_BRIDGE_URL,GASHBOARD_BRIDGE_TOKEN ^
  --allow-net 127.0.0.1,localhost src\gashboard.grab
  3. Open Your Private Browser Control Panel: Navigate to http://127.0.0.1:9390/gashboard.

3. Daily Operator Workflows

Adding a VPS Server Safely

Enter your server label, SSH host/IP, port, and OpenSSH SHA256:... fingerprint from ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub. Gashboard pins the fingerprint and rejects any impostor server with code GASH-E502.

Opening a Private Database Tunnel

Select PostgreSQL, MariaDB, or Redis and click Open Secure DB Tunnel. Gashboard binds strictly to 127.0.0.1:<local_port> (capped at 8 active tunnels) and displays a password-free connection command such as psql -h 127.0.0.1 -p 15432 -U <db_user> <database>.

Deploying & Rolling Back Site DNA

Paste a portable Groxy AI Site DNA JSON bundle, click Validate Site DNA & Lockfile Diff, inspect the preview card, and click Approve & Push Zero-Downtime Rollout. A single-use approval_token is consumed, a Pre-Deploy Snapshot is saved automatically, and 1-Click Rollback restores the previous known-good state with /_ready HTTP 200 verification.
